# 行业财务观察台

用于个人研究的公开财务数据浏览网站。支持申万一、二、三级行业、15项年报指标、个股勾选与数值筛选、行业中位数及市值重点曲线。手机可使用“选择个股”和“数值筛选”面板，点击曲线查看公司详情。

## 数据与口径

- 财务、分类、市值均为静态快照，日期显示在页面中，不代表实时行情。
- 年报报告期为12月31日，缺失不填零，当前行业归属回溯历史。
- 收入和利润为营业总收入与归母净利润；单位、计算方法、优选规则在页面中明确标注。
- 商誉字段目前缺失，该指标显示暂无数据；银行指标存在部分年份缺失。
- 公司简介只包含已缓存的公开简介，其余公司提供公开来源链接。
- 优选仅为指标参考，不代表投资建议或买入推荐。
- 此仓库仅包含网页与上市公司公开财务快照，不包含数据库原文件、访问凭据、个人持仓或账户资料。

## 运行与发布

本项目无需安装依赖或运行Python后端，使用任意静态HTTP服务器即可预览。

GitHub Pages：Settings → Pages → Deploy from a branch → main → / (root)。

更新数据需要在原始本地工作区执行 `python financial_gui/export_static.py`，审核生成文件后提交到此仓库。网站不会自动采集或更新行情。
